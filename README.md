# 🌍 Wanderia

Wanderia is a full-stack travel accommodation web application where users can explore, search, and manage travel listings.

## ✨ Features

- 🏡 Browse travel listings
- 🔍 Search destinations by title or location
- 👤 User authentication and authorization
- ➕ Create new listings
- ✏️ Edit and delete listings
- 📷 Upload listing images
- ⭐ Add reviews and ratings
- 🗺️ Location-based listing information
- 💾 MongoDB database
- 🔐 Secure sessions and authentication
- 📱 Responsive design

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript, Bootstrap, EJS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Authentication:** Passport.js, Express Session
- **Image Storage:** Cloudinary

## 🎯 Purpose

Wanderia was built as a full-stack web development project to practice and implement CRUD operations, RESTful routing, authentication, database management, image uploads, sessions, and server-side rendering.
